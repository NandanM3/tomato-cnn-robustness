# LeafVision

Evaluating the reliability and practical viability of CNN-based early-stage plant disease detection under simulated real-world conditions.

**Paper:** [arXiv link — pending] · **Author:** Nandan Menon

## What this is

A CNN-based tomato disease classifier (EfficientNet-B0, transfer learning) is evaluated not just on clean, curated images, but against twelve synthetically degraded test conditions approximating real field capture conditions — inconsistent lighting, blur, sensor noise, and low resolution. The goal isn't building the most accurate possible classifier; it's measuring how much accuracy a modern architecture actually loses under realistic conditions, and what that means economically for low-cost agricultural deployment.

**Key findings:**
- Clean-baseline accuracy: 94.98% (macro F1: 94.55%)
- Gaussian blur is the primary failure mode: accuracy collapses to 49.04% at severe severity, a 45.94-point drop
- Gaussian noise is handled robustly: only a 3.55-point drop even at severe severity
- A from-scratch (non-pretrained) comparison model, while far weaker overall, outperforms the transfer-learning model under severe blur and severe brightness/contrast degradation.The transfer-learning advantage is not uniform across degradation types

Full methodology, results, and discussion in the [paper](#) (link pending arXiv submission).

## Data

This project uses a tomato-leaf subset of the [PlantVillage dataset](https://github.com/spMohanty/PlantVillage-Dataset). Raw and processed images are not committed to this repository (see `.gitignore`) — download PlantVillage separately and run `models/common/split_dataset.py` to reproduce the 70/15/15 train/val/test split used in this study.

## Reproducing the results

```bash
pip install -r requirements.txt

# 1. Split the dataset (after downloading PlantVillage — see Data above)
python models/common/split_dataset.py

# 2. Train both models (transfer + from-scratch) — see models/ for training scripts

# 3. Evaluate on the clean test set
python experiments/phase2_clean_eval/evaluate_clean.py

# 4. Generate the twelve synthetically degraded test sets
python experiments/phase3_degradation/generate_conditions.py

# 5. Evaluate the frozen model against all degraded conditions
python experiments/phase4_robustness_eval/evaluate_degraded.py

# 6. Aggregate results into summary tables and degradation-curve plots
python experiments/phase4_robustness_eval/aggregate_results.py
```

To reproduce the from-scratch model comparison, repeat steps 3–6 with `MODEL_PATH` in each script pointed at `models/baseline_scratch/` instead.
